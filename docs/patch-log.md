| 2026-04-23 | **Toggle Mode Lab/One cassé — `MODE_TOGGLE_COOKIE = undefined` côté RSC** : Le cookie `mpp_active_view` était bien posé (visible DevTools + middleware) mais le layout serveur retournait toujours `activeMode='lab'`.
